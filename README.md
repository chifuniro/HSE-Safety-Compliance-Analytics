 HSE Safety & Compliance Analytics

 Project Overview
 
This Power BI portfolio project explores Health, Safety and Environmental (HSE) performance using a structured dataset covering incidents, hazards, inspections, corrective actions, and site exposure.

The dashboard demonstrates how data analytics can support safety performance monitoring, compliance tracking, and data-driven decision-making.

Objectives

- Analyse incident patterns and safety performance.
- Monitor corrective action status and closure.
- Explore hazards and inspection activity.
- Present key performance indicators through interactive dashboards.
- Support evidence-based operational reporting.

Tools Used

- Microsoft Power BI
- Power Query for data preparation
- Data modelling and DAX measures
- Data visualisation and KPI reporting

Dataset

The project uses a sample HSE dataset covering 2024–2026, including incident records, hazard categories, inspections, corrective actions, site information, and monthly exposure data.
